# UX terms

Status: Active

This is the canonical vocabulary for visible user interface components, and their code-facing names. Use the exact component terms in UI text and accessibility-visible names; use the mapped lower-camel or snake-case names in implementation identifiers when a component is represented there.

## Canonical components

| Visible label | Code-facing name | Meaning |
|---|---|---|
| Main | main | Root tab for the main diary view. |
| Benefits | benefits | Root tab with an explanatory empty state in v1. |
| Calendar | calendar | Root tab with an explanatory empty state in v1. |
| Plugins | plugins | Root tab with an explanatory empty state in v1. |
| All | all | Root tab with no diary snippets for now; provides Settings, Pending Recordings, and Failed Recordings entries. |

Other component labels remain undecided.
