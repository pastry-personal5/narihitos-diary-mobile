## Scope

- Register `ndm.transcription.cohere` for explicit English and Korean hints, with no automatic method, language, backend, or model substitution. Add accessible Settings installation, progress, readiness, and explicit selection to the shared method flow. Installing the model does not select Cohere automatically.
- Bundle native runtime code with the signed app; download only the selected GGUF data artifact through a manifest-bound installer. Validate URL/revision, allowed HTTPS redirect hosts, exact bytes, SHA-256, runtime compatibility, backup exclusion, and atomic publication before readiness. Preserve a verified installation across interrupted, corrupt, concurrent, or low-space replacement attempts.
- Show the exact download size before user initiation and preflight the peak space needed for staging, publication, any preserved verified copy, and the approved 1 GiB free-space requirement. Stream the download to a bounded file rather than memory and keep request URLs, redirects, paths, and digests out of diagnostics.
- Convert verified M9 audio to 16 kHz mono Float32 with explicit end-of-input, draining, sample accounting, bounded memory, and cancellation. Process versioned silence-aware chunks whose runtime inputs never exceed 45 seconds. Primary spans must cover the input once without gaps; bounded overlap at hard speech boundaries is permitted only when it is explicit, covered by provenance, and joined without fuzzy deletion or ambiguous repeated-word loss.
- Require explicit `en` or `ko`, selected Metal execution, success and nontruncation for every attempted chunk, complete chunk settlement, and a bounded usable final result. Reject ambiguous seams, runtime/backend mismatch, partial completion, truncation, oversized output, and unusable final text without publishing a partial candidate.
- Snapshot the exact verified model/runtime/conversion/chunking identities and publish through the protected M11 candidate and queue barrier. Cancellation, timeout, removal, relaunch recovery, and model/audio leases must relinquish all runtime work before the queue advances.
- Add fault-injection, integration, and target-phone evidence for installation, upgrade/revocation behavior, offline inference, English/Korean seam completeness, Metal selection, resource use, cancellation, lifecycle recovery, accessibility, and network/privacy boundaries. M13 adopts the candidate as the managed body; M14 handles iCloud publication.

## Implementation review evidence (2026-11-02)

The review found that a Cohere candidate could previously carry a self-consistent but unapproved runtime or conversion identity. The validator now requires the pinned identities, the claimed language's locale, and exactly the thirteen approved effective-setting fields. The inference adapter also checks the explicit language mapping and discards a result if cancellation arrives after seam assembly. The installer checks cancellation after artifact verification and before publication, and opens its installation record as a bounded regular file without following a symbolic link. Regression cases cover unapproved candidate fields/runtime and a linked installation record.

The owner marked implementation done on 2026-11-02, except for the by-human test and evidence. The target-phone checklist remains unchecked; the unavailable full gate remains unchecked and is reported as a validation blocker.
