# UX information architecture

Status: Active

The Standard Layout is the conceptual containment model for the app. It records structure only; visual and interaction rules are in [ux-gui.md](ux-gui.md).

## Planned root

The root contains five sibling tabs: Main, Benefits, Calendar, Plugins, and All. Main contains the full active-folder diary collection, loaded on demand with infinite scrolling, and a floating Record entry. All contains no diary snippets for now and provides entries to Settings and separate Pending Recordings and Failed Recordings screens. Benefits, Calendar, and Plugins contain only explanatory empty states. Asset detail places title and diary text before metadata at the bottom; Favorite sits beside the title, and the replay entry is inside metadata. Other metadata controls remain undecided.
