# UX information architecture

Status: Active

The Standard Layout is the conceptual containment model for the app. It records structure only; visual and interaction rules are in [ux-gui.md](ux-gui.md).

## Planned root

The root contains five sibling tabs: Main, Benefits, Calendar, Plugins, and All. Benefits, Calendar, and Plugins contain only explanatory empty states in v1. Further containment for Settings, the asset list and detail, recording, queue status, and audio replay remains undecided.
